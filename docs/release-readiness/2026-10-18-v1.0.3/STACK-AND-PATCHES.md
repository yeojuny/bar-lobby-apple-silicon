#1.0.3 stack and scope

The [1.0.2 stack](../2026-10-18-v1.0.2/STACK-AND-PATCHES.md) and [integrated component ledger](../../stack-records/2026-10-17/README.md) remain applicable. SDL/Loader/MVK/Mesa/OpenAL, AI, numeric/sync policy, nano and GS capability policy are unchanged. Audio stays OpenAL mixing → CoreAudio → output device.

Only healthbar/tracker native archive routing, dedicated healthbar shader paths, generator/fixtures and release bindings change. Other delegates retain full-handler checks. This is not a promise of universal compatibility with future widget APIs or atlases.
