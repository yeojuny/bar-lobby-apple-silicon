# r75 — typed instance upload

**Problem:** `InstanceDataFromImpl` generated `SInstanceData` records, repacked them into a static `std::vector<uint32_t>`, then passed them through generic attribute conversion into the CPU shadow. The vector was reused: it was not necessarily allocating on every call.

**Change:** validate the uint4 attribute and trivially-copyable 16-byte record contract, then copy the typed records to the corresponding CPU-shadow attribute. A tightly packed layout uses a bulk copy; a mixed layout keeps the correct per-record stride and attribute offset. A single instance uses stack storage.

**Work removed:** unnecessary uint32 repacking and generic per-attribute conversion of an already validated instance format. GPU upload and the CPU shadow remain.

**Contracts retained:** ownership/layout checks after Lua `__len`, offset checks without unsigned-wrap acceptance, correct mixed-attribute upload span, untouched CPU shadow attributes and index-restart invalidation. Multiple IDs are fully resolved into typed staging before any shadow bytes are committed, so an invalid later ID cannot partially modify the destination. That staging has a memory cost and is intentional.

**Extraction:** [patch 2](0002-r75-typed-instance-upload.patch), after patch 1, modifies `LuaVBOImpl.cpp/.h` only. It adds an explicit `<type_traits>` include for its static assertion. The original r75 stage also touched Matrix/projectile APIs; that separate optimization is deliberately excluded from this focused instance patch.

**Evidence:** both instance overloads, the helper and their ownership/data-generation checks match the current production methods byte-for-byte. They are covered by the existing full current-source CPU fixture (2,024 cases / 41,666 assertions). The separated source also passed the existing layout/Lua fixture; it was not rebuilt or GPU-tested as a complete engine. [Hashes, association and limits](validation.json).

**Performance:** no isolated per-patch FPS gain established. Historical slow and faster r75 runs both remain part of the evidence; neither is discarded to claim a gain.

**Status:** equivalent implementation retained in the published port sources; local checks only as scoped above; no individual upstream submission or official Recoil approval.
