# r73 — direct Lua-number upload

**Problem:** `LuaVBOImpl::Upload` collected the Lua input into a temporary `std::vector<lua_Number>`, then converted that array into the existing VBO CPU shadow.

**Change:** a call-local iterator uses the same raw Lua numeric getter and zero fallback. The existing conversion core consumes the iterator and writes directly to the owned CPU shadow. Vector callers retain a wrapper around the same core.

**Work removed:** the whole-input temporary numeric array's allocation, initialization, extra stores and rereads. Numeric conversion and the final GPU `SetBufferSubData` upload remain; this is not zero-copy or persistent mapping.

**Contracts retained:** SafeCast behavior, selected attributes, mixed strides/padding, partial-input bounds, error handling, index-restart proof invalidation, CPU Download contents and GPU upload ranges. Lua length callbacks can delete/redefine the VBO or change ownership; current storage/layout/ownership is revalidated after the callback before any shadow write. Engine-owned buffers are rejected.

**Extraction:** [patch 1](0001-r73-direct-lua-number-upload.patch) modifies only `LuaVBOImpl.cpp/.h`, keeps the historical header guard, and folds in later callback safety checks. No Matrix, simulation, shader, queue or power-policy change.

**Evidence:** current Upload and UploadImpl methods match this extracted result exactly. The existing real-Lua CPU fixture passed for the separated result. [Exact hashes/results and limits](validation.json). Historical r73 CPU/runtime results are not presented as fresh validation of this newly separated artifact.

**Performance:** less preparation follows from the removed operations, but an individual FPS gain has not been established. One historical r73 Metal4 pair was approximately unchanged; cumulative whole-stack gains must not be assigned to this patch.

**Status:** implemented locally and retained in published source; local CPU checks as documented; no individual upstream submission or official Recoil approval. No proof that no other project has implemented a similar idea.
