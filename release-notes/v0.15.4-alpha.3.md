# BAR for Apple Silicon 0.15.4-alpha.3

Unsigned experimental Apple Silicon/macOS 27 release. Fixes the launcher leaving a content downloader behind when it quits during downloading. Ordinary quit and Chobby handoff now drain parent-owned downloads before exit; detached menu/helper ownership is preserved. An unconfirmed shutdown reports failure and keeps the launcher alive.

An actual packaged-app quit during a live automatic download passed: downloader terminated before launcher exit 0, zero owned processes, no forced test cleanup. Existing CPU tests passed (34 main lifecycle, 17 source, 10 packaged integration). Native engine/runtime bytes and accepted NoGS are unchanged from alpha.2; the native caption still identifies that alpha.2 compatibility build. No new game, FPS, energy, full multiplayer, endurance, physical iMac or clean-machine result is claimed. Historical failures remain disclosed.

Both Metal3 and Metal4 Chobby menu checks also passed: real helper connections, parent exit 0 and natural native/helper cleanup, without running a multiplayer game.

One BAR.app provides bar-lobby and Multiplayer (Chobby). Settings selects Metal3 (default) or Metal4 (experimental) for the next native launch. The app is ad-hoc signed, without Developer ID or notarization. The DMG/ZIP, corresponding sources, notices and SHA256SUMS are attached; GitHub's automatic launcher archive alone is not the full corresponding source.

Install: `brew install --cask yeojuny/bar/bar-apple-silicon`

Upgrade: `brew update` then `brew upgrade --cask yeojuny/bar/bar-apple-silicon`

See the repository's alpha.3 release-readiness notes for the shutdown policy and remaining limitations.
