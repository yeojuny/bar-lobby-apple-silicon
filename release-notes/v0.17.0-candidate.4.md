# 0.17.0-candidate.4 — newer Lobby, Chobby and AI loading fixes

Experimental ARM64 release for **Apple Silicon / macOS 27+**. One BAR.app includes bar-lobby and Multiplayer (Chobby), with Metal3 default and Metal4 selectable in Settings. No Developer ID/notarization.

This publishes the newer Lobby `e2c45c8f` + Recoil `01efdf4` integration, retaining Chobby's official `2026.07.04` multiplayer identity. The exact Lobby engine name is `2026.09.01-24-g01efdf4 master`. Shared graphics runtime and NoGS/CUS/numeric/SHIELD policies remain intact; CPU submit wait and custom cost collection remain OFF.

Compared with alpha.3, it includes target-display/fullscreen corrections, single-flight Chobby transitions, checksum/game ownership and downloader close/drain. BARb/CircuitAI JsonCpp internals are isolated on both lanes. Chobby uses the configured Apple linker to fix invalid Mach-O alignment from a third-party linker; AI algorithms and C interfaces are unchanged.

Latest checks: 859 unit tests, Node/Web types, existing sensor fixtures, all 52 native loader checks, actual load of both AIs on both lanes, strict app signature and exact DMG/ZIP readback. The user confirmed the manual local session. The final candidate additionally has a link-only Chobby engine correction verified by loader and exact sync-version checks; that final relink has not been graphically rerun. Different-Mac testing is the next step. No fresh full multiplayer/replay synchronization, CircuitAI gameplay, endurance, FPS or energy claim.

Sound/map shading defaults are enabled; the corrected private validation profile is not shipped and saved user preferences are preserved. Earlier uncontrolled minimap captures do not establish a Metal4-specific defect.

Update an existing personal-tap installation:

```sh
brew update
brew upgrade --cask yeojuny/bar/bar-apple-silicon
```

For a first installation use `brew install --cask yeojuny/bar/bar-apple-silicon`. Quit BAR normally before upgrading. DMG and ZIP contain the same app; corresponding source, notices and checksums are attached. Alpha.3 assets remain immutable for rollback. No local installed app was replaced during publication.
