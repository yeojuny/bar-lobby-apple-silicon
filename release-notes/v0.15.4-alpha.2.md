# BAR for Apple Silicon 0.15.4-alpha.2

Unsigned experimental release for Apple Silicon and macOS 27 or later. One BAR.app contains bar-lobby and Multiplayer (Chobby), with Metal3 default and Metal4 experimental selectable in Settings for the next native launch.

This compatibility update restores the reviewed Options and tracker widgets under the current official Lua sandbox, selects the accepted Nano/Energy NoGS paths without failed GS compilation, corrects target-screen fullscreen bounds/safe-area handling, and adapts current font, map-edge, VBO and CUS lookup interfaces. OpenGL 4.6, GLSL 460, CUS GL4, the accepted explicit NoGS presentation, engine network identities and simulation settings are preserved. The window caption now shows alpha.2 / R95 + VBO + R4 without changing peer version labels.

Actual hidden Lobby checks showed damaged-unit healthbars and Settings in Metal3 and Metal4, with Ultra/4x MSAA preserved and native exit 0. Metal3 also completed launcher and child cleanup normally. The Metal4 run required cleanup of an automatic content downloader that outlived the launcher: this inherited limitation remains, and the run is not a complete lifecycle pass. Both current Chobby menu checks passed with genuine helper connections and natural cleanup; no multiplayer game was run.

No new FPS or energy benefit is claimed. Historical performance evidence, including slower samples, remains in the repository. Full public multiplayer, complete effect-animation parity, endurance, physical iMac transitions and clean-machine installation remain unverified. Read the release-readiness documentation before relying on this experimental build.

Download the DMG or ZIP, matching preferred-source archive, third-party notices and SHA256SUMS below. The app has ad-hoc integrity signatures and is not Developer ID signed or notarized. The sources include both native engines and the compiled presentation catalog/generator; GitHub's automatic launcher-only source archive is not the complete corresponding source.

Homebrew: `brew install --cask yeojuny/bar/bar-apple-silicon`; existing cask users can update their tap and upgrade that cask after publication. The cask installs one BAR.app and contains no data-deletion or quarantine-removal hooks.
