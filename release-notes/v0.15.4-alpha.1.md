# v0.15.4-alpha.1 — BAR for Apple Silicon

One **BAR.app** brings together bar-lobby, **Multiplayer (Chobby)** and a shared **Settings → Metal3 / Metal4 (experimental)** choice. Metal3 is the default; changes apply to the next native launch. Requires **Apple Silicon and macOS 27 or later**.

The app is ad-hoc signed, without Developer ID/notarization. Apple's [per-app opening instructions](https://support.apple.com/en-us/102445) describe Privacy & Security → Open Anyway after an opening attempt. This documented option is not a clean-machine procedure tested for this release. No quarantine-removal hook or global security change is included.

## Included

- Distinct native bar-lobby `2026.09.10-0-g694e9df7` and Chobby `2026.07.04` lanes, shared graphics runtime and renderer preference.
- Corrected SHIELD_POWER conversion, cumulative graphics functional changes and custom diagnostics compiled out.
- Electron 44.7.2 with the locked dependency graph, pinned runtime assets, corresponding sources and notices.
- Original launcher/installer artwork, one installed app and disabled automatic app updates. Install through the [personal Homebrew tap](https://github.com/yeojuny/homebrew-bar) with `brew install --cask yeojuny/bar/bar-apple-silicon`. The cask was loaded and checked locally; a clean-machine Homebrew installation has not been tested.

## Validation and limits

The exact release app passed ordinary Chobby Metal3/Metal4 menu handoffs and one short default-Metal3 Jade Empress game with native exit 0 and visible Lobby return. Renderer settings behavior was checked on the preceding UI-fixed package; native functional checks are bound through unchanged native runtime bytes. The exact app inventory is `6f8908edf3f81deda984e9ec5f5fd3ee31b5c5a46bcb2b803343ae3bf201a02d`. See [bounded validation](../docs/release-readiness/2026-10-15/README.md) for the actual checks and source bindings.

No fresh FPS result, clean-machine rebuild, comprehensive peer acceptance or full long-session guarantee is claimed. Historical R80 Metal3 mean FPS was 26.92% above RUN95 + VBO in a fixed-scene series with one sample per arm; Metal4 was 9.64% below Metal3 there. Those are whole-stack historical observations. [Performance details](../docs/release-readiness/2026-10-15/PERFORMANCE.md) preserve all samples and conditions.

Prior human public Scav play led to the scoped SHIELD_POWER investigation. Its 84 recorded Windows-reference comparisons matched; that does not establish that every multiplayer desync is resolved or transfer old peer/game acceptance to this package.
